# Server Monitor (iOS)

Minecraft-Server-Status-App in SwiftUI (iOS 16+). Java & Bedrock, Spielerliste, MOTD, Server-Icon, Auto-Refresh alle 30 s.

## IPA bauen
Repo auf GitHub hochladen → Tab **Actions** → Workflow **Build IPA** läuft automatisch (oder "Run workflow").
Nach ca. 5 Minuten unter dem Lauf bei **Artifacts** `ServerMonitor-ipa` herunterladen (ZIP mit der unsignierten `ServerMonitor.ipa`).
Die IPA muss beim Installieren signiert werden.
